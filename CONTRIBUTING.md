# Contributing

Keep changes focused on the six released training variants. Do not add experiment outputs, local paths, credentials, unrelated baselines, or obsolete launchers.

Before submitting a change:

1. Review every changed line.
2. Run the relevant tests and include the commands and results in the pull request.
3. Search open issues and pull requests for duplicate work.
4. Disclose AI assistance in the pull request when it was used.
5. Add an appropriate commit trailer, for example `Co-authored-by:` or `Assisted-by:`.
